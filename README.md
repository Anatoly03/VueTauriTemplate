This repository is a template for working with Vue + Tauri-based desktop applications. By forking or cloning this repository you get access to a codebase supporting a feature-full with bare-minimum content application with proper CI/CD and testing configuration.
<!--  -->

### Running

```sh
npx tauri dev
```

To start the application in a development build, assuming you have Rust and Node.js installed, first run `npm install` to update dependencies, then `npx tauri dev` to start the application.
